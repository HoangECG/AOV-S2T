<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Registered Tauri commands -> native evidence driver | Real native outcomes cross explicit inherited handles as CNG-HMAC-authenticated frames; PowerShell receives neither handles nor session key. |
| Trusted launcher/build pins -> native driver/app | Driver and app expectations are fixed outside operational request data; changing the trusted scripts/binaries/pins is outside the file-fabrication threat and remains reviewable trust-base change. |
| Native evidence driver -> durable report | The driver validates the live session and writes the report directly; no standalone envelope is accepted as attestation. |
| Target hardware/processes -> evidence writer | External device/worker/app outcomes become verification claims. |
| Local raw logs -> committed report | Potentially sensitive machine/audio metadata is redacted for durable evidence. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-13-NI | Spoofing | native command receipts | high | mitigate | Driver-generated CNG key/challenge, explicit inherited-handle allow-list, HMAC-authenticated frames, exact launched-process handle/image validation, and no production receipt/evidence import. |
| T-01-13-EV | Spoofing / Tampering | evidence validation | high | mitigate | TargetPc rejects standalone envelopes; independently reviewed driver/app pins plus direct driver-owned validation/report write replace request hashes and unkeyed envelope digests. |
| T-01-13-ST | Repudiation | stale/copied evidence | high | mitigate | Unique driver-generated run/challenge, expiry, HMAC chain, current native provenance, and deterministic replay/fabricated/rehashed-envelope tests. |
| T-01-13-TB | Tampering / Elevation | same-user trusted-code or process compromise | high | accept | Phase 1 explicitly trusts reviewed launcher/probe scripts and pinned native binaries and does not claim resistance to their replacement, debugging, memory extraction, injection, or post-run report rewrite; stronger assurance requires code signing or hardware-backed keys. |
| T-01-13-SK | Repudiation | skipped/not-tested paths | high | mitigate | Missing or nonaffirmative states fail; required/available backend lists are explicit. |
| T-01-13-AU | Information Disclosure | raw logs/report | high | mitigate | Ignore raw logs and emit redacted hashes/timings/states only; forbid content fields. |
| T-01-13-DS | DoS | interactive target run | low | accept | A failed/interrupted run keeps partial local logs and can be rerun without changing known-good config. |
</threat_model>
