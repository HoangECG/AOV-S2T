<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Pinned upstream source -> local native binary | Third-party C/C++ code becomes an executable worker. |
| Build output -> runtime inventory | Untracked executables and DLLs become eligible for execution. |
| Worker stdout/stderr -> Rust host | Child-process output is untrusted and may contain content or oversized data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-09-SC | Tampering | source/build artifacts | high | mitigate | Immutable upstream revision, repository-owned wrapper source, fixed backend flags, and SHA-256 of every release file. |
| T-01-09-EX | Elevation of Privilege | worker launch | high | mitigate | Fixed checksummed executable paths, no shell, no caller-provided executable or manifest path. |
| T-01-09-PR | Tampering / DoS | JSON protocol | high | mitigate | Exact schema, caps, timeout, exit/identity/model checks, and exact fixture transcript gate. |
| T-01-09-AU | Information Disclosure | stderr/diagnostics | high | mitigate | No audio/transcript/path data in diagnostics; transcript remains transient stdout consumed locally. |
| T-01-09-RP | Repudiation | missing candidate semantics | medium | mitigate | Required candidates return nonzero and evidence records inventory/build/checksum identities. |
</threat_model>
