## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| React local state -> native mutations | Stale or forged client state could attempt illegal transitions. |
| Native snapshot -> rendered readiness | UI could mislabel incomplete evidence as passing. |
| User cancellation -> native resources | UI interruption must stop capture and destroy sensitive candidate audio. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-12-RD | Spoofing | completion/Ready UI | high | mitigate | Render native step/readiness/canComplete only; client flags never serve as proof. |
| T-01-12-CN | Information Disclosure | cancel/retry/error | high | mitigate | Await one native cleanup transaction and reset local state in `finally`. |
| T-01-12-BM | Tampering | benchmark matrix | high | mitigate | Display native measured report unchanged; no package-state-to-pass mapping. |
| T-01-12-AC | Repudiation / Accessibility | status and recovery | medium | mitigate | Text labels plus color, fixed copy, focus order, keyboard actions, and visible blocking checks. |
</threat_model>
