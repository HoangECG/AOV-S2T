<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| React IPC -> native audio | GUI supplies opaque endpoint IDs and capture transitions. |
| Windows endpoint -> capture memory | Device-controlled formats and sensitive PCM enter the host. |
| Package/source -> binary | Approved dependencies remain pinned and lockfile-controlled. |
| Future model/worker -> host | Audio output must later enter only a bounded verified worker contract. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-02-EI | Spoofing / Tampering | endpoint identity | high | mitigate | Exact opaque ID comparison, source-kind validation, display labels non-authoritative, no default substitution. |
| T-01-02-AU | Information Disclosure | captured PCM/diagnostics | high | mitigate | Bounded local buffers, no content logs, release buffers promptly, diagnostics expose only numeric state. |
| T-01-02-DO | Denial of Service | endpoint notifications/packets | medium | mitigate | Nonblocking callbacks, bounded queues, format validation, clean close on invalidation. |
| T-01-02-MD | Tampering | model/download | high | mitigate | Audio plan exposes no activation path; later activation consumes only checksum-verified model state. |
| T-01-02-WO | Tampering / DoS | worker output | high | mitigate | No worker parsing here; normalized PCM crosses later through the bounded runner contract only. |
| T-01-02-SC | Tampering | npm/crates lockfiles | high | mitigate | Use only Plan 01-approved package identities and committed exact lockfiles. |
</threat_model>
