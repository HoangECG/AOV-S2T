## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Worker source/build -> bundled executable | Native third-party code becomes a local child process. |
| Host -> worker -> host | Sensitive local audio enters a process and untrusted JSON returns. |
| Model/worker manifests -> admission | Checksums/revisions gate compatibility and execution. |
| Benchmark diagnostics -> GUI | Timing/hardware data is visible; audio/transcript content must remain private. |

| T-01-06-MD | Tampering | model/worker manifests | high | mitigate | Exact source/build/model revisions and SHA-256 compatibility before benchmark/admission. |
