## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-03-EI | Spoofing / Tampering | device UI and harness | high | mitigate | Exact opaque ID/source-kind commands, display label non-authoritative, no default substitution. |
| T-01-03-AU | Information Disclosure | meter/harness output | high | mitigate | Numeric state only, bounded local buffers, no raw PCM or transcript persistence. |
| T-01-03-DO | Denial of Service | event subscriptions/device loss | medium | mitigate | Typed bounded events, capture stop on invalidation, explicit retry/reselection. |
| T-01-03-SC | Tampering | existing dependencies | high | mitigate | Reuse Plan 01-approved exact dependencies and committed lockfiles. |
</threat_model>
