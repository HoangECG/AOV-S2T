<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Manifest/download origin -> local storage | Untrusted network bytes attempt to become an active model. |
| React IPC -> installer | GUI can request status/download/retry but cannot choose arbitrary URLs or paths. |
| Local model -> future worker | Data is admitted only after immutable manifest, size, and checksum verification. |
| Audio/diagnostics -> UI/logs | No audio or transcript content belongs in model acquisition diagnostics. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-04-MD | Tampering | manifest/model download | high | mitigate | Immutable approved origin/revision, TLS allowlist, expected size, SHA-256, temporary file, atomic promotion. |
| T-01-04-PP | Elevation / Tampering | install destination | high | mitigate | Host-owned fixed data directory, no GUI path/URL injection, model treated as data and never executed. |
| T-01-04-WO | Tampering / DoS | future worker output | high | mitigate | Model readiness remains separate from backend readiness; only Plan 05 bounded worker parser may consume it. |
| T-01-04-AU | Information Disclosure | diagnostics | medium | mitigate | Report byte counts/hash state only; never raw audio/transcript content. |
| T-01-04-EI | Spoofing | endpoint identity | medium | mitigate | Model commands cannot mutate selected-source records; opaque endpoint authority remains in native audio module. |
| T-01-04-SC | Tampering | package/source dependencies | high | mitigate | Reuse Plan 01-approved exact dependencies/lockfiles and approved upstream artifact identity. |
</threat_model>
