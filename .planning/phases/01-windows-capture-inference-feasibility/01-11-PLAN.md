## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| React -> setup commands | Untrusted UI requests attempt to advance or commit native state. |
| Native model/worker/source evidence -> candidate | Multiple local subsystems contribute readiness predicates. |
| Candidate -> known-good file | Uncommitted values replace persistent configuration. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-11-RD | Spoofing | setup commands | high | mitigate | Commands derive proof from native state and expose no boolean/profile/config setters. |
| T-01-11-CF | Tampering | config load/commit | high | mitigate | Version/schema validation, all-predicate gate, temp write/sync/validate/atomic replace, preserve old bytes. |
| T-01-11-EI | Spoofing | official source | high | mitigate | Natively validated exact ID/kind plus current signal and one-shot inference on that source. |
| T-01-11-AU | Information Disclosure | candidate/setup state | high | mitigate | No PCM/path/transcript fields; cleanup occurs inside complete/cancel commands. |
| T-01-11-RP | Repudiation | Ready and drift | medium | mitigate | Immutable diagnostic snapshot with model/worker/profile/fingerprint timestamps and blocking reasons. |
</threat_model>
