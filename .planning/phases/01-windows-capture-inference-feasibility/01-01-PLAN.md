## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm/crates/GitHub -> build | Third-party package and worker provenance enters the executable. |
| React IPC -> native host | Untrusted GUI command arguments request endpoint enumeration/capture. |
| Windows endpoint -> capture memory | Opaque endpoint identity and sensitive PCM enter the process. |
| Future model/worker -> host | No model or worker may be activated without later verification and bounded parsing. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01-SC | Tampering | package/source installs | high | mitigate | Blocking provenance checkpoint before manifest edits or installs; exact versions and lockfiles after approval. |
| T-01-01-EI | Spoofing | endpoint selection | high | mitigate | Treat endpoint ID as opaque authority, label as display-only, and never substitute a default endpoint. |
| T-01-01-AU | Information Disclosure | PCM/diagnostics | high | mitigate | Bounded in-memory PCM, no raw audio/transcript logging, local Tauri surface only. |
| T-01-01-WO | Tampering / DoS | worker/model boundary | medium | mitigate | No activation path in this plan; reserve verified model and typed bounded worker contracts for Plans 04-05. |
</threat_model>
