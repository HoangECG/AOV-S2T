<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Worker source/build -> bundled executable | Native third-party code becomes a local child process. |
| Host -> worker -> host | Sensitive local audio enters a process and untrusted JSON returns. |
| Model/worker manifests -> runner | Checksums, revisions, fixed paths, and compatibility gate execution. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-05-WO | Tampering / DoS | worker process/output | high | mitigate | Fixed checksummed paths, no shell, strict capped JSON, timeouts, exit/revision checks, unprivileged child. |
| T-01-05-MD | Tampering | model/worker manifests | high | mitigate | Exact source/build/model revisions, complete file inventory, SHA-256 compatibility before launch. |
| T-01-05-AU | Information Disclosure | worker IO/logs | high | mitigate | Only the explicitly redistributable immutable test fixture is packaged; user audio remains separate. Bounded local IO, no result transcript logging, typed hash/identity diagnostics only. |
| T-01-05-SC | Tampering | worker source/dependencies | high | mitigate | Plan 01-approved upstream identity, pinned source commit, reproducible build script, artifact manifest/checksums. |
</threat_model>
