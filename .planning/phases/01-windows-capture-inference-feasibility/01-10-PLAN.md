<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Captured PCM -> temporary worker input | Sensitive user audio crosses from the WASAPI buffer to a local child process. |
| Worker result -> benchmark scorer | Untrusted transcript/timing/diagnostics influence backend selection. |
| Benchmark report -> setup/UI | Only non-content evidence may survive the transaction. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-10-AU | Information Disclosure | temporary PCM/WAV | high | mitigate | Bounded native ownership, private path, no IPC path/bytes, RAII deletion on all outcomes. |
| T-01-10-WO | Tampering / DoS | worker result | high | mitigate | Reuse sealed preflight, exact fixture gate, strict caps/timeouts/schema/identity before scoring. |
| T-01-10-BS | Spoofing | benchmark measurements | high | mitigate | Native coordinator calculates warm RTF/p95/correctness; React cannot submit rows or profile values. |
| T-01-10-RP | Repudiation | selected backend | medium | mitigate | Preserve build/model/fixture/hardware/timing and explicit fallback/failure reasons without content. |
</threat_model>
